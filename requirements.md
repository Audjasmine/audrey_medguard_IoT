I am building a web app to ENHANCE SOFTWARE TESTING TECHNIQUES FOR IOT BASED
HEALTHCARE SYSTEMS

Below is what the project is about:

1.4 Aim
To implement an integrated software testing framework that should significantly enhance the
security of IoT healthcare devices through the embedding of the Hill Climbing algorithm in test
case prioritization and blockchain technology for secure and traceable logging.
1.5 Research Objectives
To prioritize security test cases using Hill Climbing Algorithm
To ensure that all major vulnerabilities are identified and mitigated through iterative testing

1.6.1 Scope
The implementation will improve the software testing techniques in wearable IoT-healthcare
devices, such as smart watches and health monitors, in use within the scope of elderly care.
The application of the Hill Climbing algorithm in the prioritization of test cases for
possible security vulnerability detection in these devices will be made.
Integration of blockchain: will manage all interactions between devices and maintain records
for data integrity and traceability
